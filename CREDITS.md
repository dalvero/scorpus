# Credits

## Upstream codebase

Scorpus is a modified personal build based on GymMane (licensed under [GPL-3.0](LICENSE)).

## Exercise illustrations

The exercise art in `assets/art/` comes from [Workout Guide](https://github.com/bryllim/workout-guide) by Bryl Lim, which builds on pose artwork from [Everkinetic](https://github.com/everkinetic/data). Both are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), and the copies in this repository remain under that same license.

Each Workout Guide frame is a 512 × 512 SVG `<path>` stored as plain-text path data per exercise (`assets/art/`) and rendered dynamically with `path_drawing`.
